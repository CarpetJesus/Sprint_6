# Sprint_6
Выборнов Никита — 6 Спринт

Проект содержит автоматизированные тесты для проверки функциональности сайта аренды самокатов. Основная цель — протестировать процесс заказа самоката с использованием Selenium и PyTest.

## 🧪 Описание

Проект реализует **автоматизированные тесты** для формы заказа самоката на сайте. Тесты проверяют:

- Закрытие уведомления о cookie.
- Ввод корректных данных (имя, фамилия, адрес, станция, телефон).
- Выбор даты доставки и срока аренды.
- Выбор цвета самоката.
- Подтверждение заказа.
- Проверку текста подтверждения "Заказ оформлен".

## 🛠️ Технологии

- **Python** — язык программирования  
- **Selenium WebDriver** — автоматизация браузера  
- **PyTest** — фреймворк для написания тестов  
- **Allure** — отчеты по тестам  
- **XPath / CSS Selectors** — локаторы элементов на странице  

## ▶️ Как запустить тесты

1. Установите зависимости:

```bash
pip install -r requirements.txt
````

2. Запустите тесты:

```bash
pytest -v Tests/test_order_bike.py
```

3. Для генерации и просмотра отчетов Allure:

```bash
pytest --alluredir=./allure-results Tests/test_order_bike.py
allure serve ./allure-results
```
